# Mapify

Mapify is a location-first Progressive Web App for finding WiFi-friendly places around Metro Vancouver.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- MapLibre GL JS
- Supabase-ready data layer
- PWA support with offline fallback

## Run locally

1. Install dependencies.
2. Copy `.env.example` to `.env.local`.
3. Fill in any keys you have.
4. Run `npm run dev`.

## What is included

- Full app scaffold
- Map-centric home page
- Search and filters
- Place details panel
- Local favorites
- Geolocation fallback to Vancouver
- PWA manifest, icons, and service worker
- Supabase schema and seed SQL
